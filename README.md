## 🧠 Project Overview

### 💡 Problem Statement
Traditional crop insurance is slow, opaque, and difficult for small farmers. AgriSure changes that using:

- Blockchain for trust and automation
- AI for risk prediction
- Digital, multilingual farmer support
- Instant claim settlements via UPI

### 🎯 Objective

- ✅ Real-time, AI-verified claim settlements
- ✅ No paperwork: everything digital
- ✅ Local-language guidance 24/7
- ✅ Transparent blockchain records

---

## 🏗️ Architecture Overview

### 🔁 Level-2 Data Flow

- Farmers interact through a React-based web portal
- AI model (Python backend) validates claims using weather/satellite data
- Smart contract (Polygon/Ethereum) processes payments instantly
- UPI handles seamless money transfers
- Supabase used to store user/policy/claim metadata

---

## 🧰 Tech Stack

### 🎨 Frontend

- **Solidity** for smart contracts

- **Polygon/Ethereum** as blockchain network
- **Web3.js** to communicate with blockchain

### 💾 Database
- **Supabase** – for real-time and secure backend data storage

## 🧪 How It Works – Step-by-Step

1. Farmer logs into the web platform
2. Submits a claim through the guided UI
3. AI verifies the crop loss using satellite/weather data
4. Smart contract validates the result and transfers money
5. Payment reaches farmer’s account via UPI
6. All actions recorded immutably on blockchain
